# 🎬 Web Series Recommendation App

A simple React-based web application that allows users to explore, view, and add web series recommendations.

## 🚀 Features

- 👤 User Details Form  
  Collects basic user information and preferences  

- 🎯 Recommendations Page  
  Displays handpicked web series with:
  - Images  
  - Summaries  
  - Ratings  

- ➕ Add Recommendations  
  Users can:
  - Suggest new series  
  - Select genre  
  - Give star ratings  
  - Write reviews  

- ⭐ Interactive UI  
  - Dynamic messages on form submission  
  - Star rating system using React state  

## 🛠️ Tech Stack

- React (Functional Components + Hooks)  
- React Router (Navigation)  
- HTML & CSS

- Handling forms and user input  
- Building interactive UI elements
