# Web Series Recommendation App

A React-based web application for discovering web series, exploring recommendations, and sharing suggestions with ratings and reviews. The project focuses on building an interactive, component-based user experience using React and modern frontend development practices.

## Overview

The Web Series Recommendation App allows users to enter their details and preferences, explore curated web series recommendations, and contribute suggestions of their own. Users can interact with recommendation forms, select genres, provide star ratings, and write reviews through a dynamic interface.

This project was built to strengthen my understanding of React components, state management, routing, and form handling.

## Features

- **User Details Form:** Collects basic user information and preferences.
- **Series Recommendations:** Displays web series with images, summaries, and ratings.
- **Add Recommendations:** Allows users to suggest web series and select genres.
- **Ratings and Reviews:** Provides star ratings and a review input interface.
- **Interactive Feedback:** Displays dynamic messages when forms are submitted.
- **Multi-Page Navigation:** Uses React Router for navigation between application views.

## Tech Stack

| Technology | Purpose |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- A modern web browser

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/minhuparthasarathy/WEB-SERIES-RECOMMENDATION-PAGE.git
   ```

2. Navigate to the project directory:

   ```bash
   cd WEB-SERIES-RECOMMENDATION-PAGE
   ```

3. Open the project in your preferred code editor.

4. Follow the project's React setup and start instructions.

   **Note:** The repository listing you shared shows an `index.html` file but does not show a `package.json`. Confirm the React setup before using commands such as `npm install` or `npm run dev`. If the application is built with React through a CDN or embedded scripts, it may run differently from a standard React project.
